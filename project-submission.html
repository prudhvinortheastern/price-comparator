Project Overview & Architecture

What is Price Comparator?

Price Comparator is a full-stack application that helps online shoppers instantly discover whether a product they are viewing on Amazon is available for less on competing retailers such as eBay and Walmart. It consists of two components working together: a Spring Boot backend API deployed to Render.com, and a Chrome browser extension that integrates with that API.

The user installs the extension and registers once with a name and e-mail. From that point forward, whenever they reach an Amazon cart or checkout page, the extension automatically queries the backend, and if a cheaper price is found elsewhere, a non-intrusive banner appears on the page with a direct link to the better deal.

Intended Audience

The primary audience is everyday online shoppers who regularly purchase products on Amazon but want confidence that they are getting the best available price. Secondary users are deal-hunters and budget-conscious students who want a passive price-watchlist without installing a bloated third-party extension.

Design Patterns
Repository Pattern — Implemented ✅

All database access is mediated through Spring Data JPA repository interfaces (UserRepository, ProductRepository, TrackedProductRepository). Business logic classes never write raw SQL; they call repository methods. This cleanly separates the persistence layer from the service and controller layers, making each independently testable — the AuthServiceTest mocks the repository entirely, so tests run in milliseconds with no database required.

Strategy Pattern — Planned (Final Version) 📋

The current CompareController returns hardcoded mock offers. In the final version, each retailer will be encapsulated as a PriceFetcher strategy. The controller will iterate over all registered strategies, collect their offers, and return the results. Adding a new retailer (e.g., BestBuy) will require only a new implementing class — the controller itself will not change.

AuthService.java — Registration Business Logic

src/main/java/com/example/price_comparator/service/AuthService.java
package com.example.price_comparator.service;

import com.example.price_comparator.entity.User;
import com.example.price_comparator.repository.UserRepository;
import org.springframework.stereotype.Service;

/**
 * Business-logic service for user registration in the Price Comparator system.
 *
 * <p>This service acts as the single authoritative place for all rules around
 * creating and retrieving user accounts. Controllers delegate to this class
 * rather than interacting with the repository directly, keeping the controllers
 * thin and making the rules easy to unit-test without starting a web server.</p>
 *
 * <p><b>Idempotency guarantee:</b> Calling {@link #register(String, String)}
 * multiple times with the same e-mail address always returns the same
 * {@link User} record.</p>
 */
@Service
public class AuthService {

    private final UserRepository users;

    /**
     * Constructs the service with the required {@link UserRepository} dependency.
     *
     * @param users JPA repository used to persist and look up {@link User} records
     */
    public AuthService(UserRepository users) {
        this.users = users;
    }

    /**
     * Registers a new user or returns the existing user for the given e-mail.
     *
     * <p>Validation rules (throws {@link IllegalArgumentException} on failure):</p>
     * <ul>
     *   <li>{@code name} must not be {@code null} or blank after trimming.</li>
     *   <li>{@code email} must contain an {@code @} character.</li>
     * </ul>
     *
     * @param name  the user's display name; leading/trailing whitespace is stripped
     * @param email the user's e-mail address; compared case-insensitively
     * @return the newly created or pre-existing {@link User}
     * @throws IllegalArgumentException if name is blank or email is invalid
     */
    public User register(String name, String email) {
        String cleanName  = name  == null ? "" : name.trim();
        String cleanEmail = email == null ? "" : email.trim().toLowerCase();

        if (cleanName.isBlank()) {
            throw new IllegalArgumentException("Name is required");
        }
        if (cleanEmail.isBlank() || !cleanEmail.contains("@")) {
            throw new IllegalArgumentException("Valid email is required");
        }

        return users.findByEmailIgnoreCase(cleanEmail)
                .orElseGet(() -> {
                    User u = new User();
                    u.setName(cleanName);
                    u.setEmail(cleanEmail);
                    return users.save(u);
                });
    }
}

AuthController.java — User Registration Endpoint

src/main/java/com/example/price_comparator/controller/AuthController.java
/**
 * REST controller that handles user authentication / registration.
 *
 * <p>The Chrome extension stores a {@code userId} in {@code chrome.storage.local}
 * after a successful registration. This ID is attached to every subsequent API
 * call so the backend can associate comparison history and tracked products with
 * the correct user.</p>
 *
 * <p>Base path: {@code /api/auth}</p>
 */
@RestController
@RequestMapping("/api/auth")
public class AuthController {

    private final AuthService authService;

    public AuthController(AuthService authService) {
        this.authService = authService;
    }

    /**
     * Registers a new user or retrieves an existing one by e-mail address.
     *
     * <p>This endpoint is idempotent: calling it multiple times with the same
     * e-mail always returns the same user record rather than creating duplicates.</p>
     *
     * <p><b>Request body:</b> { "name": "Alice", "email": "alice@example.com" }</p>
     * <p><b>Success (200):</b> { "userId": 1, "name": "Alice", "email": "..." }</p>
     * <p><b>Error (400):</b> { "error": "Valid email is required" }</p>
     *
     * @param body JSON map containing {@code name} and {@code email} keys
     * @return 200 OK with user details, or 400 with an error message
     */
    @PostMapping("/register")
    public ResponseEntity<?> register(@RequestBody Map<String, String> body) {
        try {
            User user = authService.register(body.get("name"), body.get("email"));
            return ResponseEntity.ok(Map.of(
                    "userId", user.getId(),
                    "name",   user.getName(),
                    "email",  user.getEmail()
            ));
        } catch (IllegalArgumentException ex) {
            return ResponseEntity.badRequest().body(Map.of("error", ex.getMessage()));
        }
    }
}

CompareController.java — Price Comparison Endpoint

src/main/java/com/example/price_comparator/controller/CompareController.java
/**
 * REST controller that drives the core price-comparison feature.
 *
 * <p>The Chrome extension's content script calls this endpoint whenever a user
 * is on an Amazon cart or checkout page.</p>
 *
 * <p><b>Design Pattern – Strategy (planned):</b> In the final version, each
 * retailer will be a {@code PriceFetcher} strategy. The controller will iterate
 * over all registered strategies and return the aggregated result.</p>
 *
 * <p><b>Current prototype:</b> Returns hardcoded mock offers to validate the
 * end-to-end pipeline before real API keys are integrated.</p>
 */
@RestController
@RequestMapping("/api")
public class CompareController {

    /**
     * Accepts a product snapshot and returns competing offers.
     *
     * <p>Request: { userId, site, url, title, price }</p>
     * <p>Response: { cheaperFound, currentSite, currentPrice,
     *   offers: [ { site, price, url }, ... ] }</p>
     *
     * @param body JSON map with product details from the extension
     * @return 200 OK with comparison result
     */
    @PostMapping("/compare")
    public ResponseEntity<?> compare(@RequestBody Map<String, Object> body) {
        // Using HashMap because Map.of() rejects null values (price may be absent)
        Map<String, Object> result = new HashMap<>();
        result.put("cheaperFound", true);
        result.put("currentSite",  body.getOrDefault("site", "unknown"));
        result.put("currentPrice", body.get("price"));
        result.put("offers", List.of(
                Map.of("site", "eBay",    "price", 149.99,
                       "url", "https://www.ebay.com/sch/i.html?_nkw="
                               + urlEncode(String.valueOf(body.getOrDefault("title","")))),
                Map.of("site", "Walmart", "price", 155.49,
                       "url", "https://www.walmart.com/search?q="
                               + urlEncode(String.valueOf(body.getOrDefault("title",""))))
        ));
        return ResponseEntity.ok(result);
    }

    /**
     * URL-encodes a product title for use as a search query parameter.
     * Replaces spaces with {@code +}.
     *
     * @param s the raw product title; null treated as empty
     * @return space-to-+ encoded string
     */
    private String urlEncode(String s) {
        return s == null ? "" : s.replace(" ", "+");
    }
}

CorsConfig.java — Cross-Origin Configuration

/**
 * Opens all /api/** routes to any origin so the Chrome extension
 * (running under chrome-extension://) can call the backend API.
 *
 * NOTE: allowedOrigins("*") should be tightened to the specific
 * extension origin once the extension ID is stable.
 */
@Configuration
public class CorsConfig {
    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {
            @Override
            public void addCorsMappings(CorsRegistry registry) {
                registry.addMapping("/api/**")
                        .allowedOrigins("*")
                        .allowedMethods("GET","POST","PUT","DELETE","OPTIONS")
                        .allowedHeaders("*");
            }
        };
    }
}

src/test/java/.../service/AuthServiceTest.java
@ExtendWith(MockitoExtension.class)
class AuthServiceTest {

    @Mock
    private UserRepository userRepository;
    private AuthService authService;

    @BeforeEach
    void setUp() { authService = new AuthService(userRepository); }

    /** Verifies new user is persisted and returned. */
    @Test
    @DisplayName("register: new user is saved and returned")
    void register_newUser_savesAndReturns() {
        when(userRepository.findByEmailIgnoreCase("alice@example.com"))
                .thenReturn(Optional.empty());
        User saved = new User();
        saved.setName("Alice");  saved.setEmail("alice@example.com");
        when(userRepository.save(any(User.class))).thenReturn(saved);

        User result = authService.register("Alice", "alice@example.com");

        assertThat(result.getName()).isEqualTo("Alice");
        assertThat(result.getEmail()).isEqualTo("alice@example.com");
        verify(userRepository, times(1)).save(any(User.class));
    }

    /** Verifies blank name throws IllegalArgumentException. */
    @Test
    @DisplayName("register: blank name throws IllegalArgumentException")
    void register_blankName_throwsException() {
        assertThatThrownBy(() -> authService.register("  ", "alice@example.com"))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessage("Name is required");
    }
}

Bug Fixed During Testing

NullPointerException in CompareController

Java's Map.of() throws a NullPointerException when any value is null. The original code passed body.get("price") (which is null when the extension omits the price field) directly into Map.of(). This was discovered by the compare_missingTitle_returnsGracefully test. Fixed by switching to new HashMap<>() which accepts null values.
